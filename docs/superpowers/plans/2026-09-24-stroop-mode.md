# Stroop Mode Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Stroop mode from spec section 13.1: a JSON pack of words drawn in colours, a word visual, an interference-cost metric, and a mode picker on Home.

**Architecture:** The engine gains one `Visual` case and one generic statistic. The app gains a bundled JSON pack (the first to exercise the JSON path in production), word rendering in `ItemView`, a `ModePickerView`, a remembered pack choice, and pack names on Results and History. No new game loop.

**Tech Stack:** As for v1. Conventions from the v1 plan apply; use `Scripts/engine-test.sh`, `Scripts/build.sh` and `Scripts/test.sh`.

### Task 2: Interference cost

**Files:**
- Modify: `Packages/SwipeSortEngine/Sources/SwipeSortEngine/RunStatistics.swift`
- Modify: `Packages/SwipeSortEngine/Tests/SwipeSortEngineTests/RunStatisticsTests.swift`

- [x] **Step 1: Tests.** Items with attributes `["ink": "red", "word": "red"]` are congruent; `["ink": "red", "word": "blue"]` are not. With three congruent correct items at 500 ms and three incongruent at 800 ms, `conflictCost == 300 ms`. With only two of one kind it is nil. Single-dimension items are never congruent, so the shapes pack yields nil.
- [x] **Step 2: Implement** `public var conflictCost: Duration?` in `RunStatistics`, computed over correct items with a reaction time, congruent when `attributes.count >= 2 && Set(attributes.values).count == 1`, requiring `minimumConflictItems` (default 3) of each kind.
- [x] **Step 3: Run** engine tests; commit.
